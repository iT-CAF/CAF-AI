# اختبار كآف AI · Testing CAF AI

## 1. الاختبارات الآلية · Automated tests

لا تحتاج إنترنت ولا نماذج حقيقية: تعمل على **Ollama وهمي** (`tests/helpers/mock-ollama.js`) ومجلد بيانات مؤقت لكل ملف اختبار.
They need no internet and no real models: they run against a **mock Ollama** and a temporary data folder per test file.

```bash
npm test            # node --test "tests/*.test.js"  (Node 20+)
```

| الملف · File | ما يغطيه · Covers |
|---|---|
| `server.test.js` | الأمان (Host/Origin/الرمز/CSP)، الترقية v1→v2 مع نسخة احتياطية، المحادثة والبث، قفل اللغة (لا صيني/روسي)، الرؤية، المرفقات، الصوت |
| `router.test.js` | الموجّه التلقائي (صور/رؤية/برمجة/عام) واختيار النموذج حسب الجهاز |
| `archive-downloads.test.js` | tar/zip، التنزيل القابل للاستئناف، التحقق من الحجم والبصمة، امتلاء القرص |
| `addons.test.js` | تثبيت المحركات والنماذج الإضافية وحذفها، سياسات CSP لعمّال Python |
| `skills.test.js` | صيغة SKILL.md والوكلاء، الاختيار التلقائي حسب مساحة العمل، الاستيراد، التعديل كنسخة واستعادة الأصل |
| `docs.test.js` | استخراج PDF/DOCX/XLSX/CSV، الفهرسة والبحث الهجين، المصادر، ملفات المحادثة |
| `images.test.js` | توليد الصور عبر sd-cli وهمي: التقدّم، الإلغاء، أخطاء الذاكرة، المعرض |
| `backup.test.js` | تصدير المحادثة (md/zip)، النسخ الاحتياطي والاستعادة مع نسخة أمان، رفض الملفات المريبة |
| `api.test.js` | واجهة ‎/v1‎: الإيقاف الافتراضي، المفتاح، Origin، auto، البث، التضمين، تدوير المفتاح |

## 2. اختبار يدوي · Manual test plan

نفّذها قبل كل إصدار، على جهازين على الأقل: **جهاز بمعالج رسومي** (Mac Apple Silicon أو NVIDIA) و**جهاز بدون معالج رسومي**.
Run before every release, on at least two machines: **one with a GPU** (Apple Silicon or NVIDIA) and **one without**.

ضع ✅ أو ❌ لكل بند · Mark each item ✅ or ❌.

### أ. التشغيل الأول · First run
- [ ] `install-caf-ai.sh` / `install-caf-ai.ps1` على جهاز نظيف: ينزّل المحرك ويفتح المتصفح على ‎127.0.0.1‎.
- [ ] صفحة «جهازي» تعرض الذاكرة والمعالج الرسومي الصحيح (Metal / CUDA / بدون).
- [ ] «الأدوات المثبّتة»: النماذج مرتبة حسب الملاءمة، وتظهر علامة «بطيء» على جهاز بلا معالج رسومي.
- [ ] تنزيل نموذج ثم قطع الإنترنت في المنتصف وإعادته ← يُستأنف التنزيل ولا يبدأ من الصفر.
- [ ] بيانات الإصدار 1.0 (إن وجدت) تُرحَّل تلقائيًا، وتُنشأ نسخة في `data/backups/pre-v2-*`.

### ب. CAF_HOME على مسار خارجي (فلاشة USB) · CAF_HOME on an external drive
- [ ] `CAF_HOME=/Volumes/USB/caf ./startcaf` (أو `set CAF_HOME=E:\caf` على ويندوز): يعمل، وكل البيانات والنماذج تُحفظ على الفلاشة فقط.
- [ ] نقل الفلاشة إلى جهاز آخر وتشغيله: المحادثات والإعدادات والمهارات موجودة.
- [ ] «جهازي» يوضّح أن القرص قابل للإزالة ويعرض سرعته.

### ج. اللغة والاتجاه · Language & direction (عربي وإنجليزي)
- [ ] الواجهة بالعربية: كل النصوص عربية، الاتجاه RTL، الكود دائمًا LTR.
- [ ] التبديل إلى English من الزر EN: الواجهة كاملة بالإنجليزية وLTR.
- [ ] سؤال بالعربية ← رد بالعربية فقط (بلا صيني أو روسي)، حتى مع temperature = 1.2.
- [ ] قائمة نقطية وجداول عربية تظهر بالاتجاه الصحيح، وفقرة إنجليزية داخل رد عربي تبقى LTR.

### د. المحادثة · Chat
- [ ] البث سلس بلا ارتجاف، والمؤشر يتحرك، وزر الإيقاف يعمل.
- [ ] نموذج «يفكّر» (qwen3.5): شريط «يفكّر…» مطوي، ويُفتح بالنقر فقط.
- [ ] «تلقائي»: سؤال عام ← نموذج محادثة، سؤال برمجي ← نموذج برمجة، صورة ← نموذج رؤية (الشارة تحت الاسم).
- [ ] نموذج غير مثبّت أو بلا رؤية ← رسالة عربية واضحة مع زر تنزيل البديل.

### هـ. البرمجة · Code
- [ ] «اكتب لي آلة حاسبة بملفات index.html و style.css و script.js» من **المحادثة**: تُفتح اللوحة، تُكتب الملفات حيًا، تبويبات الملفات، والمعاينة تعمل بالتنسيق.
- [ ] من مساحة **كود**: صفحة HTML ← معاينة مباشرة بأحجام الأجهزة الثلاثة، Console يعدّ الأخطاء.
- [ ] برنامج Python ← زر «التشغيل» ينبض ← المخرجات صحيحة (أول مرة: تنزيل Pyodide بموافقتك).
- [ ] كود يحاول `fetch` أو `import` من الإنترنت ← يُمنع داخل الصندوق المعزول.
- [ ] «اطلب تعديلًا» على جزء محدد ← نسخة جديدة + الفروق.
- [ ] إرفاق مجلد مشروع ← يتجاهل node_modules و.git ويعرض تقدير التوكن.

### و. الصور · Images
- [ ] لصق صورة (⌘V) وسحبها وإرفاقها ← «صف الصورة» يرد عنها بدقة.
- [ ] تثبيت محرك الصور + FLUX.2 klein من صفحة «صور» ← توليد 512 بتقدّم حقيقي وإلغاء يعمل.
- [ ] «ارسم لي قطة…» في المحادثة ← تُولَّد الصورة داخل المحادثة.
- [ ] على جهاز بلا معالج رسومي: تحذير الوقت يظهر قبل البدء.

### ز. المستندات · Documents
- [ ] PDF نصي ← سؤال عنه مع مصادر [1].
- [ ] PDF ممسوح ضوئيًا ← قراءة بالرؤية (OCR).
- [ ] Excel + «أضف عمود الإجمالي واجعل العناوين عريضة» ← ملف جديد صحيح يُنزَّل، والأصل لم يتغير.
- [ ] Word + «صحّح الأخطاء» ← ملف ‎.docx‎ جديد.
- [ ] مكتبة المعرفة: إنشاء مجموعة، إضافة ملفات، السؤال عنها من محادثة أخرى.

### ح. المهارات · Skills
- [ ] «/» يعرض الأوامر والمهارات، والبحث بالعربية يعمل.
- [ ] استيراد `/Applications/Agency Agents.app/Contents/Resources/resources` ← المهارات تظهر وتعمل.
- [ ] «عرض» مهارة ← المحتوى منسّق + المعلومات الجانبية. «تعديل» ← حفظ، ثم «استعادة الأصل».
- [ ] «مهارة جديدة» بأمر مختصر ← تظهر في «/» فورًا.

### ط. الصوت · Voice
- [ ] تفعيل الصوت ← زر الميكروفون ← تفريغ عربي صحيح.
- [ ] «استمع» يقرأ الرد بصوت محلي.

### ي. التصدير والنسخ والتحديث والـAPI
- [ ] تصدير Markdown / HTML / PDF لمحادثة فيها صور.
- [ ] نسخة احتياطية ← حذف محادثة ← استعادة ← المحادثة عادت، ونسخة الأمان موجودة.
- [ ] الإعدادات ← التحديثات ← «تحقق»: يعرض الإصدار الأحدث من GitHub، والتحديث يعيد التشغيل بالإصدار الجديد.
- [ ] الواجهة البرمجية: معطّلة افتراضيًا، ثم مثال curl من الإعدادات يعمل، وتدوير المفتاح يلغي القديم.

### ك. الأمان · Security
- [ ] `curl -H "Host: evil.com" http://127.0.0.1:3737/api/info` ← 403.
- [ ] طلب POST من صفحة موقع آخر ← 403 `bad_origin`.
- [ ] لا يستمع الخادم إلا على 127.0.0.1 (`lsof -i :3737`).
- [ ] لا أخطاء في Console المتصفح أثناء الجولة كاملة.

### ل. الوصول والاستجابة · Accessibility & responsive
- [ ] التنقل بلوحة المفاتيح فقط (Tab / الأسهم / Esc) في الشريط الجانبي والقوائم والنوافذ.
- [ ] قارئ الشاشة (VoiceOver / NVDA) يقرأ أسماء الأزرار.
- [ ] عرض 390px (جوال): الشريط الجانبي ينزلق، اللوحة الجانبية بعرض كامل، ولا قص في الأزرار.
